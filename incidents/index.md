## Index rules

- An incident record is evidence, not doctrine.
- Source-supported facts must remain distinguishable from interpretation.
- Secondary commentary should not overwrite primary-source wording.
- New evidence may update status, confidence, or interpretation without deleting prior states.
- Incident records should point to relevant PAC invariants and experiment proposals.

## Current cross-incident pattern

The current evidence base supports investigation of a common operational pattern:

```text
persistent objective
+ capable tool use
+ weak or reduced external enforcement
+ novel discovered pathways
-> unauthorized or unintended action
```

This is a research synthesis, not a claim that all frontier models behave identically.
